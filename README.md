# PookieFinder 💘 — HTML + CSS only

A playful, fictional campus matchmaking website made with plain HTML and CSS.

## Files
- `index.html` — page content and forms
- `style.css` — layout, styling, animations, and the CSS-only delayed result reveal
- `hearts-background.jpg` — pink hearts background
- `pookie-nilgai.png` — nilgai image with pink bows shown as the match result

## Run locally
Open `index.html` in a browser. Keep all four assets/files in the same folder.

## Publish on GitHub Pages
Upload all project files to the root of your repository, then go to **Settings → Pages** and select **Deploy from a branch → main → /(root)**.

## Important limitation
This project intentionally uses **no JavaScript**. Clicking “FIND MY MATCH” opens the search section; CSS displays the nilgai result after a 5.5-second suspense animation. CSS cannot actually read the form answers, randomly choose matches, or query a real database. The search and match are fictional, and form data is not sent or saved. Do not enter sensitive personal information.
